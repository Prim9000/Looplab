Python value assignment

A variable is a named box. The = sign doesn’t mean “equals”: it means “put this value into the box”.

The rule

variable_name = value  ←  right side is worked out first, then stored on the left

Remember

In total = total + 1, Python first reads the old value of total (0), computes 0 + 1 = 1, then throws away the old value and stores 1. The box only ever holds one value.
