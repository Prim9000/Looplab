The idea

Without a loop, printing five greetings means writing five lines. With a for loop, you write the instruction once and let Python repeat it.

for name in ["Ada", "Alan", "Grace"]:
    print("Hello,", name)
OutputHello, Ada Hello, Alan Hello, Grace

Read it as: “for each name in the list, do the indented block.” Each pass through the block is one iteration. Python gives the loop variable the next value every time, so you never update it yourself.

Anatomy. The line ends with a colon, and the body is indented (four spaces by convention). Indentation is how Python knows what is inside the loop.

Counting with range()

When you need numbers, use range(). It takes up to three arguments: range(start, stop, step). The stop value is never included, and start defaults to 0, step to 1.

for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 8, 2):    # 2, 4, 6
    print(i)

for i in range(10, 0, -3):  # 10, 7, 4, 1
    print(i)

A loop that runs n times is range(n), and it counts from 0. This off-by-one habit is the most common source of student bugs, so check your boundaries every time.

Looping over collections

You can loop directly over lists, strings, tuples, dictionaries and more. Prefer this over indexing; it is shorter and harder to get wrong.

for letter in "code":
    print(letter)

scores = {"Mia": 91, "Leo": 78}
for student, score in scores.items():
    print(student, score)

for i, fruit in enumerate(["apple", "pear"], start=1):
    print(i, fruit)
Output (last loop)1 apple 2 pear

Use enumerate() when you need the position as well as the value, and .items() to get dictionary keys and values together.

Pattern: the accumulator

Most loops build something up. Start with a neutral value before the loop, then update it inside.

total = 0
for price in [4.5, 3.0, 12.25]:
    total += price
print("Total:", total)

evens = []
for n in range(1, 11):
    if n % 2 == 0:
        evens.append(n)
print(evens)
OutputTotal: 19.75 [2, 4, 6, 8, 10]

The initial value matters: 0 for sums, 1 for products, [] for lists, "" for strings. Define it before the loop, or it will reset on every pass.

Steering a loop: break and continue

break exits the loop immediately. continue skips the rest of the current iteration and moves to the next one.

for n in range(1, 10):
    if n == 3:
        continue      # skip 3
    if n == 6:
        break         # stop at 6
    print(n)
Output1 2 4 5

Python also has a for … else: the else block runs only if the loop finished without hitting break. It is handy for searches.

Nested loops

A loop inside a loop runs its full cycle for every iteration of the outer one. With 3 rows and 4 columns, the inner body executes 3 × 4 = 12 times.

for row in range(1, 4):
    line = ""
    for col in range(1, 5):
        line += str(row * col) + " "
    print(line)
Output1 2 3 4 2 4 6 8 3 6 9 12

Common mistakes

Expecting range(5) to include 5. Changing a list while looping over it. Forgetting the colon. Putting the accumulator’s starting value inside the loop. Writing for i in len(items) instead of range(len(items)).
